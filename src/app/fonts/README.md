# Google Sans Flex (Latin, 400 to 600)

`google-sans-flex-latin-400-600.woff2` is Google Fonts' Latin subset of Google Sans Flex, instanced to the weight range
400 to 600 (variable), as served by `https://fonts.googleapis.com/css2?family=Google+Sans+Flex:wght@400..600`.
Downloaded 25 Oct 2026, unmodified.

Licence: SIL Open Font License 1.1 (https://openfontlicense.org), as published on Google Fonts
(https://fonts.google.com/specimen/Google+Sans+Flex/license). Self-hosted so the v8 homepage loads 38 KB instead of the
51 KB full weight axis (src/app/fonts-v8.ts).
