# Logo sources: "Connectors on the roadmap" strip

Checked 2026-10-08. simple-icons reference release: 16.34.0 (npm). Use case: showing a vendor mark on our site to say
an integration is on the roadmap (nominative use, no endorsement), rendered single-colour white at 70% opacity.

Rule applied: a mark is used only if it is official AND the owner's published terms allow third-party logo use on a
commercial site without a partner agreement AND allow a single-colour rendering. Otherwise the brand is a text tile.

What ships (homepage v3): every connector is a text tile, as the design draws them (Altium, KiCad, OrCAD, SolidWorks,
Fusion, Teamcenter, and "+3" for Arena PLM, Git and Jira), each with a "<Tool> · Roadmap" tooltip. Git is the only
brand whose terms allow its logo, but the design groups it in the "+3" tile, so no logo file is shipped and no
attribution is needed. If Git ever gets its own tile, use the official icon below and add the CC BY 3.0 credit.
